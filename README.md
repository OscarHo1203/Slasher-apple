# Slasher Apple

## Introduction
**Slasher Apple** is a tycoon-style game developed entirely in **Godot Engine**. Inspired by the popular mobile game *Fruit Ninja*, it combines fruit-slashing gameplay with tycoon mechanics, allowing players to earn money and progress through the game.
